# Zepto Data & AI Platform

This is my complete Data and AI capstone project. It is broken into three main parts:

**1. Data Pipeline (`data_pipeline/`)**
This part scrapes data from the web, cleans it up, and saves it into a database.

**2. Analytics & Machine Learning (`analytics/`)**
This part loads Titanic passenger data, creates helpful charts to understand the data, and trains an AI model to predict who survived.

**3. GenAI Assistant (`genai/`)**
This part is a smart chatbot workflow. It uses a "Mock" (fake) AI setting so we can safely test the chatbot without paying for real API costs.
